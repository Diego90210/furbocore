# Code Conventions

> Extreme consistency. AI performs better when the repository looks like itself everywhere.

## Python Style

* **Version:** Python 3.13.
* **Formatting:** PEP 8. Maximum line length of 100 characters.
* **Imports:** stdlib first, then third-party, then local. One module per line.
* **Strings:** Always use double quotes `"..."`. Single quotes only to escape double quotes inside strings.
* **f-strings:** Use f-strings for interpolation. No `.format()` or `%`.

## TypeScript / React Style

* **Formatting:** 2-space indent, double quotes for JSX attributes, semicolons.
* **Components:** Function components only. `"use client"` directive at the top when hooks or browser APIs are used.
* **Imports:** React/Next first, then third-party, then local (`@/` aliases not used — relative paths).
* **Styling:** Tailwind utility classes inline. No CSS modules, no styled-components.
* **Data fetching:** Server components by default. `fetch` with `next: { revalidate }` for ISR. Client fetch only for interactive search.

## Naming

| Type | Convention | Example |
|---|---|---|
| Python modules | `snake_case` | `transfer_value.py` |
| Python classes | `PascalCase` | `RandomForestRegressor` |
| Python functions / variables | `snake_case` | `build_training_set` |
| Python constants | `UPPER_SNAKE` | `FEATURE_COLS` |
| Python private | `_` prefix | `_batch_upsert` |
| React components | `PascalCase` | `PlayerSearchBox` |
| React files | `PascalCase` for components, `snake_case` for pages | `PlayerCard.tsx`, `page.tsx` |
| React hooks | `use` prefix | `useState`, `useEffect` |
| Tailwind classes | utility-first | `bg-white rounded-2xl shadow-sm` |
| DB tables | `snake_case` plural | `player_stats`, `transfer_values` |
| DB columns | `snake_case` | `real_value_eur`, `goals_per90` |
| Env vars | `UPPER_SNAKE` | `NEXT_PUBLIC_SUPABASE_URL` |

## File Structure

Every Python file in `src/` starts with:

```python
"""One-line description of the module's purpose."""

# stdlib imports
import os

# third-party imports
import pandas as pd

# local imports
from src.features.transfer_value import FEATURE_COLS
```

Every React component file:

```tsx
"use client";  // only if hooks/browser APIs are used

export default function ComponentName() {
  return ( ... );
}
```

## Database

* All tables have RLS enabled with `SELECT` for `anon`.
* Frontend reads via `anon` key. Writes only via `service_role` in Python.
* Use `upsert()` with `on_conflict` — never raw `insert()` for repeatable data.
* Batch upserts: `BATCH = 200`. Never one API call per row.
* UUIDs generated by Postgres (`gen_random_uuid()`), not by application code.

## Error Handling

Python pipelines raise named exceptions:

```python
class IngestionError(Exception):
    """Base class for ingestion errors."""


class MissingEnvVar(IngestionError):
    """Raised when a required environment variable is not set."""
```

Catch at the `run_pipeline.py` level and exit with code 1. Never let a traceback reach the CI log as the only signal.

React pages always have a matching `error.tsx` and `loading.tsx`. Error pages use `reset()` to retry. Never `alert()`.

## Tests

* One test file per module: `tests/test_<module>.py`.
* One `test_*` function per acceptance criterion.
* Use `tempfile.TemporaryDirectory()` for any file I/O and clean up.
* Descriptive names: `test_build_training_set_returns_265_rows`.
* Frontend: `npm run lint` and `npm run build` must pass — these are the gates.

## Comments

By default, **do not** write comments. They are only allowed when they explain a non-obvious *why* (e.g., a documented workaround or subtle invariant). Names should communicate everything else.

## Data Sources

* Transfermarkt snapshot is frozen since Jul 2026 — treat as static, do not try to refresh.
